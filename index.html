Carpeta de PDF

Selecciona la única carpeta pdf del móvil. Copia dentro de ella todos los PDF: artículos, grúas, fichas, catálogos y fichas publicitarias. La aplicación no los copia a la base de datos ni los sube a GitHub.

Todos los documentos pueden estar juntos. La aplicación localiza el PDF por el nombre guardado en material.db. Si Android conserva el permiso, intentará recordar la carpeta.

Información

Material Móvil v1.2 es una aplicación de consulta. La base y los PDF permanecen en tu teléfono.

Para actualizar los datos, vuelve a importar una copia reciente de material.db.

Usa una única carpeta pdf. Cuando un registro tiene PDF, el enlace aparece sobre Descripción en Artículos/Fichas, Modelo en Grúas y Nombre en Catálogos/Fichas publicitarias.
